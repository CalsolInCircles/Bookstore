# 📚 Bookstore: My Library Scanner App

A Flutter app that helps you build a personal digital library by scanning book barcodes using your device’s camera and saving book details (including title, author, and cover) to your Firebase account.

More features to be added.

---

## ✨ Features

- 📷 Scan ISBN barcodes using your phone’s camera
- 🔍 Fetch book information from Google Books API
- 💾 Store books in your own Firebase Firestore collection
- 👤 Login/logout with Firebase Authentication
- 🖼️ View book covers in a clean, simple interface
- 📁 Persistent library per user

---

## 🛠️ Technologies

- **Flutter** (UI framework)
- **Firebase** (Auth + Firestore)
- **Google Books API** (book data)
- **camera** + **google_ml_kit** (barcode scanning)
